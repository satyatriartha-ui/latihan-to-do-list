# To-Do List App

Sebuah aplikasi web sederhana untuk mengelola daftar tugas harian (To-Do List). Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript murni (Vanilla JS) dengan antarmuka yang bersih dan responsif.

## 🚀 Fitur

- **Tambah Tugas**: Menambahkan daftar tugas baru.
- **Tandai Selesai (✓)**: Mengubah status tugas menjadi selesai (teks akan dicetak coret).
- **Hapus Tugas (🗑️)**: Menghapus tugas dari daftar.
- **Dukungan Enter**: Dapat menambahkan tugas dengan menekan tombol `Enter` pada keyboard.
- **Validasi Input**: Menampilkan peringatan jika pengguna mencoba menambahkan tugas kosong.
- **Pesan Kosong**: Menampilkan pesan "Belum ada tugas." jika semua tugas telah dihapus.

## 📂 Struktur File

Proyek ini terdiri dari tiga file utama:

1. `index.html` - Berisi struktur halaman utama dan elemen UI [cite: 1].
2. `style.css` - Berisi gaya desain (styling) untuk mempercantik tampilan antarmuka dengan tema warna biru [cite: 3].
3. `script.js` - Berisi logika fungsionalitas aplikasi seperti manipulasi DOM untuk menambah, menyelesaikan, dan menghapus tugas [cite: 2].

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- Vanilla JavaScript

## 💻 Cara Menjalankan

1. Pastikan Anda memiliki ketiga file tersebut (`index.html`, `style.css`, `script.js`) dalam satu folder yang sama.
2. Buka file `index.html` menggunakan *web browser* (seperti Google Chrome, Mozilla Firefox, atau Safari).
3. Ketikkan tugas Anda pada kolom input dan klik tombol **Tambah** (atau tekan `Enter`).

## 🎨 Tampilan UI

Aplikasi ini menggunakan perpaduan warna yang memanjakan mata, dengan warna latar belakang biru muda cerah dan tata letak *card* berwarna putih yang berada di tengah halaman. Tombol aksi (selesai dan hapus) dibedakan dengan warna hijau dan merah untuk memudahkan pengguna.
